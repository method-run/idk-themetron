idk-themetron

playground

Make a tree of themes from a few colors, fonts, and feels. Themetron makes accessible design tokens, and the components on the right use them.

Sets are saved in this browser. Download a set from the Tokens view to keep it.
A child takes every setting that it does not override from its parent. A child that changes only its color is a color theme.

Mode

Tokens hold both modes. Each color picks its light or dark value where it is used.
